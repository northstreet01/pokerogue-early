# Windows LAN 版使用说明

当前发行入口：build/desktop/release/PokeRogue-LAN-win32-x64/PokeRogue-LAN.exe。必须保留整个发行目录，不能只复制EXE；玩家无需安装Node或外部浏览器。更新前先退出旧程序，新包验收后清理旧包。个人数据在系统AppData/PokeRogue-LAN，不随安装包清理。

## 进入游戏

大厅提供单人、联机、恢复已有联机、个人收藏及档案管理。个人备份、导入和恢复使用大厅的档案操作；桌面“程序”菜单另提供整个个人SQLite数据库的备份/恢复。旧“单人基础与本地收藏”网页已删除，不再作为存档入口。

单人选好队伍后确认存档槽，可鼠标点击或按Enter。覆盖非空槽位仍需确认。首次教程按提示继续；若保存失败，不要清空资料，请保留现场反馈。

大厅“宝可梦图鉴”直接打开原版精灵网格与详情：已解锁显示彩色，见过但未捕获显示灰色，未知为黑影；确认可查看累计最佳IV，也可切换已解锁的形态、性别、特性和性格。这里展示本人永久资料，不展示队友临时共享的选队权限。

单人和联机选择同一个人档案时，共用同一份图鉴、成就、券和统计。遇见、捕获当时更新图鉴数据；单人随原保存节点（如新遭遇）落盘，联机在房主确认的安全节点写入本人档案，不必等通关。不同个人档案保持独立；原浏览器旧资料仍应显式迁移，不自动覆盖。

“个人资料”查看原版蛋、券、成就与统计界面。“本地档案 / 存档管理”选择档案后，可用“冒险存档（3个槽位）”查看原版三槽卡片的波次、时间和队伍；该一览只读。继续单人冒险仍从“单人冒险→读取存档”进入；联机冒险由原房主保存，从“恢复已有联机”进入。

## 两人合作

双方先在大厅的档案管理中创建或选择个人档案，再进入联机。新版新房间会将遇见、捕获、IV、进化、原成就和券等成果写回本人档案；共享选队权限不写入永久图鉴。保存失败时点击“重试保存成果”，房主会保留待确认成果；不要删除档案或换用另一份席位凭据。旧房继续原恢复方式，不补发旧奖励，蛋进度和孵化仍待后续。

1. 同一局域网：进入“联机冒险 → 局域网联机”。房主点击“启动本机房主”（默认TCP18735），然后创建房间；队友在自动搜索结果中点击房主，无需填写IP。
2. 异地连接：切到“远程联机”，填写房主IP或域名，例如 `172.16.2.5`（默认18735）或 `example.com:映射端口`；也支持完整HTTP/HTTPS地址。连接后输入六位房间码，计数应为6/6。房间码只标识所连接房主上的房间，不能代替跨网连接地址。
3. 双方选队，确认“完成选队”只保存队伍。查看双方两排精灵后各自点击“提交准备”；双方同步且准备完成才开始。
   新版新房间会先同步双方的临时共享图鉴，任意一方解锁的初始精灵双方都可选；同一物种只能由一人选用，形态/闪光也算同种。取消选择并同步后释放占用。该共享不写入彼此的永久图鉴；旧房继续原方式，双方须使用同版程序。
4. 局内道具可悬停、聚焦或点击看原说明、持有者和剩余次数。已准备时先取消准备才能改队。

整备已支持回忆蘑菇及一批原持有物/经验/金钱道具。形态道具按原条件生成并应用，包含Mega、极巨化、太晶化；DNA融合打开原队伍菜单，先选主体再选本人第二只。第二只离队，原持有物转移及学招流程完成后继续；解除融合不返还第二只。不能选择队友精灵融合。新抽取奖励会排除未接入机制，旧存档已有未支持奖励不重抽、不静默替换，可改选或跳过。原版所有特殊道具、形态开关和概率效果尚未全部验收。

同机个人测试可用EXE作房主，再以独立浏览器打开 http://127.0.0.1:18734 作另一客户端，连接 http://127.0.0.1:18735。两个客户端保留各自资料与凭据，不复制同一席位token。真人两设备仍需另外手测。

虚拟局域网使用房主虚拟IP加游戏端口；穿透使用映射后的房主地址。不要把n2n supernode地址当成游戏地址。游戏不设置隧道、防火墙或路由。本机18734仅提供本地资源，不能映射它代替18735房主服务。

局域网自动发现由桌面程序使用UDP18736广播，房主启动服务后响应；约1.5秒结束一次搜索，可手动刷新。访客Wi-Fi、AP隔离、不同子网或未转发广播的虚拟网络可能搜不到，这时展开“未找到？手动连接”，填写房主地址；浏览器没有UDP发现能力，也使用此入口。发现结果仍需通过HTTP核对房主身份，再进入原房间协议；广播不传个人档案、房间凭据或战斗状态。新进入联机页不会自动连接上次房主，恢复已有联机仍沿已保存的房主/席位。

## 数据与恢复

个人档案、单人进度、设置、席位与outbox存于 storage/personal.sqlite；房主冒险位于 hosts/formal-rooms。个人数据库恢复不回滚房主房间。恢复菜单会先留保护备份，确认后重启；只在可丢弃档案上测试恢复。

断线或暂停后重启原房主，以原host身份、房间和私有席位恢复。“卡住脱离／重载存档”回最近可靠检查点，不是任意历史回滚。失败候选输入撤回需要双方连接确认，存储失败不得强行清除。详见[恢复约束](coop-checkpoint-recovery-review.md)。

## 开发与验收

Node使用项目要求版本（CI为24）。依次执行 npm ci、npm run review:code、npm run typecheck、相关测试、npm run build:desktop、npm run package:desktop。默认只使用build/desktop，不再用每批新目录。npm run start:desktop运行尚未封装的app产物；运行发行包直接启动EXE。打包前必须退出正在使用的目标包。

当前验证与手测范围见[验收记录](desktop-lan-review.md)，代码审查和清理要求见[维护要求](DEVELOPMENT-HANDOFF.md)。
