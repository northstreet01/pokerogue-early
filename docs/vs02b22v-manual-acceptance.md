## 验收顺序

1. **蓄力续招**：使用火箭头锤等原两回合招式。第二回合本人应执行原续招，伙伴仍可正常选择攻击、换人或合法丢球，不强制本人重新选招。若原规则要求选择目标，只显示本人目标菜单，取消后能重新选择。
2. **再充能**：破坏光线命中并执行后，下回合本人按原规则休息，伙伴照常行动；双方都需休息时不出现没人能提交的等待。休息不再次扣 PP。
3. **Encore**：被再来一次影响时，FIGHT 仅能使用原被锁定招式，仍保留原允许的换人/用球操作。不能凭客户端旧菜单绕过限制。
4. **断线与恢复**：在自动续招目标菜单、伙伴已选操作时刷新其中一端。恢复后伙伴操作不丢失、不重复扣 PP/球，也不要求另一端重选已确认动作。
5. **入场能力**：遇到原入场能力/能力等级变化时，应依原顺序展示并进入可操作战斗，不能卡在初始入场。
6. **八项远程故障回看**：继续按[八项复测表](vs02b22w-manual-acceptance.md)检查并发糖果、瞬间移动、满员等待、丢球组合、加载、满血用药返回、异常图标和退出残图。本批构建已包含这些修复，但仍需要真人确认。
