## 本批行为

原选队页在联机时显示“完成选队”。确认后先同步队伍，再以现有 `profile-ready / ready:false` 确认选队，返回房间；不再自动提交 `ready:true`。玩家查看双方队伍后手动准备。未完成确认、仍在选队、提交中、同步失败或双方尚未同步时，准备入口不可用。已经准备时先取消准备才能重新选队。服务端原双方准备与状态确认屏障保持不变。

双方各一排六个槽位，本人排在前，显示原精灵图标、名称、原点数、编辑／确认／准备状态。预览只读取房主已接受的公开选队投影；本地尚未接受的编辑不冒充队友已看到的结果。沿用公开物种与形态，不新增公开 IV、招式、蛋、收藏、种子，也不凭空显示未公开的闪光或性别。

本人局内道具改为原 items 图集图标、数量和悬停／键盘聚焦／点击说明，使用原本地化名称及效果描述，显示携带者和有效战斗次数。包括后备精灵携带物。只读取恢复后的副本，不调用 apply、不改 HP、PP、背包、余额、规则随机数或摘要。此处复用原美术、类型及描述，列表容器是适应联机 DOM HUD 的展示层，并非直接搬入会修改原场景的完整 Phaser 道具栏。

增加独立状态行，区分队友连接、双方加载核对、行动已提交／仍在选择，以及共享整备完成／仍在购物。原同步故障与恢复操作继续显示在独立错误区域。新增展示没有持久化字段；原队伍与明确准备操作仍沿原事务保存，鼠标及逐帧动画不写入。

## 手测

1. 双方加入同一房间，分别选队并点“完成选队”；两排图标、点数和双方已选队／未准备应一致。
2. 仅一方准备必须留在房间；双方准备并加载完成后进入战斗。准备后重新选队应要求先取消准备。
3. 获取本人道具后查看图标和层数，悬停、聚焦或点击查看效果、携带者与剩余次数；关闭说明不应触发战斗操作。
4. 一方选动作、另一方等待；战后分别购物，核对各自状态。断线／重连后继续同房同席，原动作和库存不重复执行。
5. 检查中文／英文、窄窗口及长道具说明。真实两设备、穿透、声音、完整长局和已有永久成果待办不因本批完成而视为已验收。
