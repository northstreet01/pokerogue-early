# 房间码输入与单人开局修复（2026-10-27）

用户手测报告：房间码第六位无法输入；单人完成选队后存档槽不能鼠标点击，按 Enter 确认后只剩背景和空文本框。仅修复本轮故障，未推进新功能批次。

## 原因与修改

大厅每次刷新都会删除并重建房间码输入框，未保留内容、焦点或光标。现在保留草稿和光标；文本键盘事件不传给游戏；新增0/6计数。输入先做NFKC、去空白与大写转换，再限制六位，避免粘贴空白占位。协议仍使用六位房间码，没有改成五位。

单人故障已用旧构建与隔离合成档案复现。主界面切换场景后，共享声音管理器保留了旧场景的停止音轨；`sound.get('menu')` 返回旧音轨，rex FadeOut复用其淡出任务，访问已销毁场景的事件对象时抛出 `Cannot read properties of null (reading 'off')`。队伍已生成，但 `SelectStarterPhase` 尚未创建第一波便中断，与用户截图一致。现改为 `scene.fadeOutBgm(500, true)`，只淡出当前场景持有的BGM。

存档槽原先没有指针绑定。现使用原槽位窗口的命中区域与统一指针入口，点击选中并确认槽位；槽位尚未读取完成时拒绝确认，回调消费后拒绝重复提交，键盘继续可用。

## 手测
