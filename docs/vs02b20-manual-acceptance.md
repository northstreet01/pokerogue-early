# VS-02B-20 原版展示与音乐手测

当前状态：维护者尚未执行真实双浏览器验收。自动化使用真实原模型、存储和WebSocket，Phaser渲染/音频设备仍是端口，不能代表实测观感。

使用两个独立浏览器profile，打开本批生产构建的根地址，从首页进入正式联机，新建/加入同一房间，沿正常个人选队进入战斗。不要用两个共享同一存储的普通标签页替代独立profile。记录构建提交、浏览器、窗口尺寸及必要录屏，隐藏席位令牌。

1. 首页、联机大厅、首战、群系野生战、训练家战与胜利分别听原BGM。确认网站已允许声音，原设置的背景音乐和总音量非零；静音设置应保持有效。同场购买、伙伴操作或同一快照广播不应从头重播同一首曲目。退出返回首页后只有首页音乐；慢加载旧战斗音乐不能覆盖首页。
2. 普通攻击、多段伤害、击倒：招式先出现，血条按事件变化，随后原倒下叫声及下沉；倒下目标在所属动画前不能提前消失。双方看相同的稳定目标和位置，空席不向左挤。
3. 本人换人、伙伴换人、强制补位：特别核对换人后同回合受击，入场先显示未受击HP，招式播放后才扣血；不能一入场就显示最终低HP。原收回缩放及精灵球飞行/释放/展开。显示跟随原权威结果；菜单不能操作伙伴队伍。非本人战前问句仍属后续修复项，不将它误记为本批已关闭。
4. 治疗、树果及上限变化：逐事件HP/血条和最终值相符，Summary/下一输入与服务器结果相符。刷新或重连直接显示最终状态，不倒放整段历史。
5. 正常打完一波、准备完毕、下一遭遇及换群系：查看原2秒场地滚动，以及换群系原延迟1秒/渐变1秒。没有重复刷新战场、旧敌人幽灵或永久黑屏。
6. 两人交错领取、购买、重抽；一人打开本人Party/目标时，另一人处理奖励。伙伴操作不关闭本人的菜单或重载场上对象；本人必要目标和非法旧选项仍受校验。购买后金额只扣一次，价格/已领取状态即时更新，原光标保持有效。重抽应按原流程显示新候选，不误保留旧候选。
7. 各动画/血条/资源加载中主动退出，立即返回首页再fresh；旧动画、音频和回调不得覆盖新房。重复退出、慢资源、服务中断、刷新恢复各检查一次。
8. 小窗口、键盘与鼠标分别完成以上关键路径。记录卡顿时刻、控制台错误与网络请求，区分浏览器整页重载和场景重新绘制。

本批不宣称全面中文、共享奖励池、自动完成整备、复杂成长和完整经验升级展示已经完成。上述画面/音频实测完成前，第二轮反馈第1/2/5及新音乐项保持待用户复测。
