# Windows LAN 版使用说明

当前发行入口：build/desktop/release/PokeRogue-LAN-win32-x64/PokeRogue-LAN.exe。必须保留整个发行目录，不能只复制EXE；玩家无需安装Node或外部浏览器。更新前先退出旧程序，新包验收后清理旧包。个人数据在系统AppData/PokeRogue-LAN，不随安装包清理。

## 进入游戏

大厅提供单人、联机、恢复已有联机、个人收藏及档案管理。个人备份、导入和恢复使用大厅的档案操作；桌面“程序”菜单另提供整个个人SQLite数据库的备份/恢复。旧“单人基础与本地收藏”网页已删除，不再作为存档入口。

单人选好队伍后确认存档槽，可鼠标点击或按Enter。覆盖非空槽位仍需确认。首次教程按提示继续；若保存失败，不要清空资料，请保留现场反馈。

## 两人合作

1. 房主进入联机冒险，显式点击“启动本机房主”，默认TCP18735，然后创建房间。
2. 队友填写房主HTTP地址，例如 http://192.168.1.8:18735，连接后输入六位房间码，计数应为6/6。
3. 双方选队，确认“完成选队”只保存队伍。查看双方两排精灵后各自点击“提交准备”；双方同步且准备完成才开始。
4. 局内道具可悬停、聚焦或点击看原说明、持有者和剩余次数。已准备时先取消准备才能改队。

同机个人测试可用EXE作房主，再以独立浏览器打开 http://127.0.0.1:18734 作另一客户端，连接 http://127.0.0.1:18735。两个客户端保留各自资料与凭据，不复制同一席位token。真人两设备仍需另外手测。

虚拟局域网使用房主虚拟IP加游戏端口；穿透使用映射后的房主地址。不要把n2n supernode地址当成游戏地址。游戏不设置隧道、防火墙或路由。本机18734仅提供本地资源，不能映射它代替18735房主服务。

## 数据与恢复

个人档案、单人进度、设置、席位与outbox存于 storage/personal.sqlite；房主冒险位于 hosts/formal-rooms。个人数据库恢复不回滚房主房间。恢复菜单会先留保护备份，确认后重启；只在可丢弃档案上测试恢复。

断线或暂停后重启原房主，以原host身份、房间和私有席位恢复。“卡住脱离／重载存档”回最近可靠检查点，不是任意历史回滚。失败候选输入撤回需要双方连接确认，存储失败不得强行清除。详见[恢复约束](coop-checkpoint-recovery-review.md)。

## 开发与验收

Node使用项目要求版本（CI为24）。依次执行 npm ci、npm run review:code、npm run typecheck、相关测试、npm run build:desktop、npm run package:desktop。默认只使用build/desktop，不再用每批新目录。npm run start:desktop运行尚未封装的app产物；运行发行包直接启动EXE。打包前必须退出正在使用的目标包。

当前验证与手测范围见[验收记录](desktop-lan-review.md)，代码审查和清理要求见[维护要求](DEVELOPMENT-HANDOFF.md)。
