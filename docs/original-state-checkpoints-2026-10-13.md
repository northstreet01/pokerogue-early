## 保存与恢复约束

1. 检查点包含 `version`、固定 `type`、`fields` 和 `undefinedFields`。明确区分原本不存在的属性与值为 undefined 的自有属性，避免 JSON 把后者静默丢掉。
2. 保存字段全部显式列出，包含 TypeScript private 字段；运行时新增未知字段会报错，测试也会核对原类及继承链的声明字段，避免新机制被静默漏存。
3. 恢复创建新对象并保留原类 prototype，不修改现有 Pokemon 实例；不调用构造器、setter、onAdd、随机源、动画、消息或 Phase 队列。恢复寄生种子不重复扣血，恢复蓄力/硬直标签不重复排队。
4. 类型 ID 不依赖 `constructor.name`，生产压缩不会改变存储标识。拒绝未知版本/类、标签与类不匹配、必需字段缺失、未知字段、访问器、非法数值和畸形数组。
5. 这是**结构校验和组件还原**，不是完整对局合法性验证。来源 ID 是否属于该局、标签组合是否合法、所有者、规则版本和完整快照哈希，仍须由未来决策状态/房间层校验。客户端不能据此提交自行生成的状态。
6. `Battle.restoreRandomState` 只接受当前 seed 与 turn 的检查点，先完整校验再更新内部随机状态；失败不改变原值。它不负责恢复场景随机流，也不能单独证明两个对局相同。
7. 编码格式或字段语义变化时必须升版本并提供明确迁移策略，不能用默认值掩盖旧状态缺失。
