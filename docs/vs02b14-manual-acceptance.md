## 两端步骤

1. 选队界面直接点“退出本局／返回首页”，应返回现有单人首页，出现“仅本人离开”相关结果。初始页点“重新进入联机”应出现建房/加入，不自动续旧房。返回后刷新也不强制回旧房。
2. 建立双端房间并正常战斗；本人提交后等待伙伴时退出。另一端应保留原房并显示断线等待；不能被解散、清档或自动重开。未确认行动不能被宣传为已经撤销。
3. 播放动画/消息时退出；按钮始终可访问，不必等动画、ACK或菜单完成。用Tab聚焦退出按钮，Enter或Space操作；Esc仍是原菜单取消。
4. 在可恢复停点关闭服务；重连等待中点击退出，应仍在短时间内回首页。服务保持关闭也不应把人困在旧画面。重启服务使用原数据目录，不清房间。
5. 退出者返回联机建新房；使用新的独立测试伙伴加入。新房不得出现旧房快照、旧回执、旧行动或旧队伍。原伙伴仍在旧房；若要参加新房，应由该伙伴本人也退出后显式加入，不自动替其切房。
6. 新房正常选队并进入可支持战斗，完成一次双方FIGHT；刷新新房双方后应恢复新房。再次退出并刷新联机页，不自动回刚退出的新房。
7. 观察已有个人收藏/蛋仍在；旧房已提交HP/PP/钱/pending捕获不被退出回滚。不要提交真实存档、房间恢复令牌或截图中私有凭据。
8. 如自然发生本地存储失败/超时，首页应显示“退出记录未确认保存”。使用该页“重新进入联机”链接可跳过旧自动恢复；新建/加入在IDB仍不可用时会明确失败。全部存储失效时，手工旧URL/新标签页的持久防恢复不保证，不把有限fallback写成持久保存成功。
