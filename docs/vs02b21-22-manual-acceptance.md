# VS21+22 与成长显示手测

当前尚未执行真实双浏览器、音频设备与帧耗时验收。自动测试使用真实原规则、IDB、磁盘和WebSocket，Phaser分配/资源/音频仍有测试端口，不能代表实际观感。最终构建提交和完整回归结果以[维护记录](mvp-vs-02b21-22-review.md)为准。

更新代码后重启正式联机服务（COOP_PROFILE_LOBBY=1），从根目录Home进入正式联机，使用两个独立浏览器profile，创建新冒险、选队并正常打完一战。旧房间没有sharedPreparation标记时保留原个人商店及手动完成，恢复旧房间不能用来判断新共享模式是否生效。

1. 入场、后续遭遇和训练家战：本人需要换人时只本人看到原问句/确认，伙伴无“是否更换对方”弹窗；强制补位仍有。刷新、断线再恢复后归属不变。
2. 免费奖励与付费商品双方看到同一有限库存；每个条目一份，每人最多一件免费奖励。付费仍各扣自己的钱，可买不同商品；一方抢先领取后另一方不能再领。目标页已打开时伙伴操作不关闭本人的Party，已售出项选择给中文解释且不扣钱。
3. 未领取/跳过前可按原价重抽，双方同步新免费候选，已购付费项不补货。任何一方结束免费选择后，重抽锁定。先购物再领免费奖励，或原取消键确认跳过，即结束本人购物；取消确认可继续选。新模式无需反复点击“整备完成”或按Enter准备。
4. 本人完成但还有学招/进化等必要选择时，仍先完成原选择再等待伙伴；两人均完成才进入下一战。恢复不能重领、重复扣款或提前推进。
5. 普通伤害、多段、治疗、树果、上限变化和换人：原血条逐事件变化，最后与Party/Summary一致，伙伴能看公开HP变化。招式→血条→倒下顺序、遭遇滚动和BGM按[VS20清单](vs02b20-manual-acceptance.md)继续复测。
6. 场上/后备获得经验、连续升级：原EXP条与后备经验提示、原升级能力值“增量→总值”两页、原音效；能力面板遵循原“显示升级能力值”设置，先开启检查双页，再关闭核查不额外弹出。显示不重算属性。升级后学招用本人原确认/招式详情，伙伴不能代选。Summary的经验、下级、性格/相遇说明及统计标签一并检查中文。
7. 自然进化或神奇糖果触发进化：先由本人确认，提交后播放原Evolution场景、精灵变化、背景视频、粒子和音乐，再回原消息界面。显示已经服务器确认的结果，动画期间不再次取消规则。取消本次后可选是否暂停今后进化；当前联机Party还不支持重新开启，提示已明确，不误导用户。进化结果的永久收藏事务仍属于M6，不能据场景认定已永久写入收藏。
8. 升级面板、进化视频/粒子和资源加载途中退出，立即回Home并fresh；旧补间/弹窗/音效/恢复音乐回调不得覆盖新房。刷新/重连直接收敛已提交状态，不重放整段旧成长场景。
9. 默认中文路径从Home、只读收藏/蛋、联机大厅、Starter到Command/Party/Summary、商店、战斗、成长、退出均检查；名字、说明、层数、价格和长文无键名/空插值。英文仍可选；外围联机状态解释部分固定中文是已记录边界。用小窗口/键鼠检查中文排版，不把HP/EXP/PP或随机专名当漏译。
