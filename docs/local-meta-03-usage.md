# 局外第三批使用与测试

本批前端产物：`build/local-meta-03/dist`。独立静态预览只监听本机，启动后打开 `http://127.0.0.1:8033/`：

```powershell
cd E:\pokeregue\pokerogue-early
node build/local-meta-03/static-preview.mjs
```

该辅助预览脚本和产物保存在本机 ignored build；源码重新取得时可使用项目正常 Vite 构建／预览。8033 不提供联机 WebSocket，不能拿这里创建房间测试远程合作；正式服务和隧道没有自动升级。浏览器本地数据按协议、主机名和端口隔离，`localhost`、`127.0.0.1`、隧道域名之间不会自动共用档案。

## 建档与个人收藏

1. 初始菜单向下找到“本地档案 / 存档管理”，选择“创建新档案”，填昵称后点原窗口的“确认”。取消不创建档案，反复点击不能重复建档。
2. 返回根菜单应显示当前昵称。刷新页面后仍保留。头像当前为默认项。
3. “个人收藏 / 蛋 / 券”显示当前档案的原版只读页面；返回不会扣券、产蛋或修改统计。
4. 创建第二份合成档案并切换，收藏与三个冒险槽必须独立。先不要拿唯一的真实存档做故障测试。

## 旧资料与备份

1. 在原资料所在的同一浏览器地址，选择“导入此浏览器旧资料”；先检查槽位／蛋预览，再决定确认或返回。来源不删除，不自动合并新旧分支。
2. 迁移后的旧冒险须在档案管理中确认属于本人；未确认时进入单人应明确停止并允许返回，不能直接覆盖旧槽。
3. “导出完整个人备份”会先说明私密范围。请保存下载文件；它包含本人收藏、蛋、账本、单人冒险和必要恢复数据，不是给朋友的房间邀请。
4. “导入备份文件”支持完整个人 JSON、旧完整备份 v1、原系统 `.prsv`。同 ID 恢复会整份替换并保留恢复点。只有单人 Session `.prsv` 不能伪造对应系统收藏，不能在这里当完整档案直接导入。
5. 坏文件／缺字段／未来版本应拒绝并保留现有档案；可从“恢复备份”选择原点、自动备份或恢复前快照。恢复不是余额叠加。

## 单人保存闭环

1. 选定档案后进入“单人冒险”，沿原欢迎／标题／新开／选队流程；不要另外改地址中的 profile 参数。
2. 正常完成第一场和奖励，到下一遭遇保存边界后用左下角返回局外，再进原继续菜单；波次、队伍和收藏应来自同一档案。
3. 同时打开同档案的第二个单人页面应提示正在使用，不创建替代空档。先退出第一个页面，再重试。
4. 返回局外会等待已排队的保存；它不会新增回合中途检查点。保存失败时保留原检查点，并明确显示未保存返回，不能把退出理解为该回合已保存。
5. 三个原槽位继续独立，已有槽的新开覆盖沿原确认；终局统计与清槽一起提交。合成写盘失败、旧回调、租约失效和终局重试由自动测试覆盖，不要求用户破坏真实档案复现。

合作满进度待终局蛋当前仅有结构和显示；存在这类蛋时，单人入口会保护性停止，防止原单人孵化消费合作保留蛋。实际推进和终局孵化待第五／六批接入。

完整范围、证据和失败历史见[维护验收](local-meta-03-review.md)。
